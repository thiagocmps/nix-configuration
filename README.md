# Nix configuration

## About

My nix configuration with my main prod tools. That's it.

## packages

### Development

#### Tools

> - **Vim**: Terminal text editor.
> - **Neovim**: Vim-based text editor.
> - **Bruno**: Open-source API client.
> - **Quickemu**: Desktop virtual machine manager.
> - **OpenCode**: Terminal-based AI coding agent.
> - **jq**: Command-line JSON processor.
> - **gh**: Official GitHub CLI tool.

### Languages/Runtimes

> - **nodejs**: JavaScript runtime environment.
> - **go**: Google's programming language.
> - **rustup**: Rust toolchain and version manager.

#### Dependencies

> - **yarn**: Node.js package manager.
> - **docker-compose**: Multi-container Docker application orchestrator.
> - **rustlings**: Interactive Rust learning exercises.
> - **tree**: Directory structure visualizer.
> - **tree-sitter-cli**: Parsing system tool for syntax highlighting.
> - **glow**: Terminal-based Markdown renderer.
> - **wakeonlan**: Script to power on remote computers.
> - **wl-clipboard**: Copy and paste utility for Wayland.

### System Analysis

> - **testdisk**: Data recovery and partition restoration software.
> - **ncdu**: Ncurses-based disk usage analyzer.
> - **dua-cli**: Terminal disk usage analyzer.
> - **duf**: Disk usage utility with colorful charts.
> - **btop**: System resource monitor.
> - **smartmontools**: S.M.A.R.T. storage monitoring utility.
> - **gparted**: Graphical partition editor.

### Stylish

> - **blesh**: Autocomplete and syntax highlighting for Bash.
> - **cava**: Console-based audio visualizer.
> - **fastfetch**: System and hardware information display tool.
